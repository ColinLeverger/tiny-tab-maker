      Connection — repository, branch, token
      

        
        
        
        
      

      
Use a private repository initialized with a README, and a fine-grained token ↗ limited to that repository with Contents: read/write. The token stays in this browser.

    


    

      Set up your iPhone — QR code
      

        

        
In the iPhone app, open Songbooks and tap Scan laptop QR to prefill the repository and token.
⚠ Treat this QR code like the token itself. Do not share it.

      

    


    

      How sync works
      
Every edit is saved on this device immediately. Once connected, edits upload to GitHub after 30 seconds, or when you leave or close the tab. Opening or returning to the app checks GitHub for a newer copy. If both copies changed, nothing is overwritten — this sheet asks which copy wins.
